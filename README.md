# 推荐系统研究训练笔记

个人：xushengqin

这个目录用于记录推荐系统研究训练期间的学习计划、每日进展、课程作业和知识沉淀。

## 目录结构

- `learning_plan.md`：阶段目标、每周计划和复盘。
- `daily_logs/`：每日学习记录、问题和下一步安排。
- `assignment/`：课程作业与提交材料。
- `knowledge_base/`：长期复用的知识笔记。
- `course_materials/`：课程资料

## 使用建议

每天结束前更新当天的 daily log；每完成一个主题后，把可复用内容整理到 knowledge base；每周在 `learning_plan.md` 中做一次计划调整和复盘。
