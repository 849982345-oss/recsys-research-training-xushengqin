# 第三次课作业：本地 GPU 环境与 SASRec Smoke Demo


## 六、GPU 训练

执行命令：

```powershell
python sasrec_demo.py --device cuda --epochs 10 --batch-size 32 --max-len 20 --hidden-size 64 --num-heads 2 --num-blocks 2 --allocator-limit-mib 700 --gpu-budget-mib 1024
```

训练配置：

| 参数 | 值 |
|---|---:|
| device | cuda |
| epochs | 10 |
| batch size | 32 |
| max sequence length | 20 |
| hidden size | 64 |
| attention heads | 2 |
| Transformer blocks | 2 |
| allocator limit | 700 MiB |
| GPU budget | 1024 MiB |
| model parameters | 59648 |

训练过程中 loss 逐步下降，验证指标逐步提升：

| Epoch | Loss | Valid HR@10 | Valid NDCG@10 |
|---:|---:|---:|---:|
| 1 | 1.3830 | 0.2578 | 0.1180 |
| 2 | 1.3470 | 0.4141 | 0.2423 |
| 3 | 1.3115 | 0.5547 | 0.3524 |
| 4 | 1.2670 | 0.6328 | 0.4510 |
| 5 | 1.2198 | 0.7031 | 0.4965 |
| 6 | 1.1691 | 0.7422 | 0.5273 |
| 7 | 1.1251 | 0.7578 | 0.5669 |
| 8 | 1.0786 | 0.7656 | 0.5916 |
| 9 | 1.0367 | 0.7891 | 0.6147 |
| 10 | 0.9981 | 0.8047 | 0.6363 |

最终结果：

| 指标 | 结果 |
|---|---:|
| Best epoch | 10 |
| Test HR@10 | 0.8672 |
| Test NDCG@10 | 0.6620 |
| Torch allocated memory | 69.8 MiB |
| Torch reserved memory | 92.0 MiB |

显存低于 1024 MiB 预算，训练过程正常完成。日志中的 `process=unavailable` 只表示程序没有从 Windows 的进程级查询接口获取到显存值；PyTorch 自身的 allocated/reserved 显存统计是正常的。

## 七、结果理解

1. Loss 从 1.3830 下降到 0.9981，说明模型在训练集上的预测逐步改善。
2. Valid HR@10 和 Valid NDCG@10 持续上升，说明真实目标物品越来越容易进入推荐列表前 10 名。
3. NDCG 不只关心目标是否进入 Top-K，还关心目标在列表中的位置。
4. Best epoch 为第 10 轮，表示在本次训练中验证集最优结果出现在最后一轮。
5. 该数据集是课程用的合成 Smoke 数据，规模很小且模式明显，因此较高指标不能直接代表真实推荐系统效果。
6. 本实验的主要目的，是验证数据管线、模型、GPU、显存限制和实验输出，而不是进行正式模型对比。
