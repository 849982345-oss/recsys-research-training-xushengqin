# 第六次课：论文阅读方法与 SASRec 精读

> 这节课解决的问题：找到一篇论文之后，怎样从“看过标题”走到“真正知道它解决什么、怎么解决、证据够不够”。课堂用 SASRec 作为示范。

## 1. 第五课到第七课的衔接

```text
第五课：找到并筛选论文
    -> 第六课：理解问题、方法和证据
    -> 第七课：定位代码并复现实验
```

所以第六课不是让你背公式，而是为下一步读代码做准备。

## 2. 一篇论文各部分分别回答什么

| 位置 | 主要问题 |
|---|---|
| 标题、摘要 | 研究对象、任务、方法和主要结论是什么？ |
| 引言 | 为什么要研究？已有方法哪里不足？ |
| 相关工作 | 本文处于哪条研究路线？和前人有什么关系？ |
| 任务定义与方法 | 输入、输出、数据流、公式和训练目标是什么？ |
| 实验 | 作者用什么数据、基线、指标和对照来证明主张？ |
| 结论 | 结论适用于什么条件？有什么限制？ |
| 附录、代码 | 哪些实现细节会影响复现？ |

阅读不是从第一页逐字读到最后一页，而是去正确的位置寻找当前问题的答案。

## 3. 三级阅读法

### 3.1 快速筛选（5--10 分钟）

只判断三件事：

1. 这篇论文和当前问题是否相关？
2. 它是否提供需要的方法、数据集、baseline 或实验协议？
3. 版本、来源、代码和数据是否可追溯？

优先看标题、摘要、引言开头、结论和主要图表。产物是“精读 / 泛读 / 备查 / 排除”以及一句理由。

### 3.2 泛读

适合了解论文讲了什么、属于哪条路线、和其他论文如何关联。主要看摘要、引言、结论、主要图表，必要时扫相关工作和方法概览。

### 3.3 精读（30--90 分钟以上，可多轮）

适合当前研究问题、领域基础方法、强 baseline，或者后续准备读代码和复现实验的论文。产物包括三问答案、方法数据流、主张—证据表和具体疑问。

## 4. 精读必须记住的三问

### 问题一：这篇论文解决了什么问题？

- 研究对象是什么？
- 输入和预测目标是什么？
- 为什么这个问题值得研究？
- 已有方法采用什么路线，具体不足是什么？
- 作者的核心假设是什么？

### 问题二：这篇论文如何解决这个问题？

把方法写成数据流：

```text
原始交互序列
    -> 输入表示（物品 Embedding + 位置 Embedding）
    -> Self-Attention Block
    -> 前馈网络 FFN
    -> 序列表示
    -> 候选物品打分
    -> 损失函数更新参数
```

同时记录：输入输出、shape、关键公式、作者新增组件和继承组件、训练目标是否对应最终任务。

### 问题三：论文如何证明它解决了这个问题？

逐项核对：

- 数据集和过滤规则；
- 训练 / 验证 / 测试切分；
- baseline 是否公平；
- 负采样和候选集如何构造；
- 指标的具体口径；
- 主实验、消融、效率、稳健性和可视化证据；
- 结论适用范围和未证明部分。

数字最高不自动说明比较公平，相关模式也不自动等于因果机制。

## 5. SASRec 用大白话理解

### 5.1 它要做什么

给定用户过去按时间排列的行为：

```text
[看了 A, 看了 B, 看了 C] -> 预测下一件可能感兴趣的物品
```

这叫序列推荐（sequential recommendation），更具体地说是下一物品预测（next-item prediction）。

### 5.2 为什么使用 Self-Attention

传统 Markov 方法通常只看很近的历史；RNN 可以看更长历史，但可能需要较多数据并且训练不够高效。SASRec 希望让每个位置根据任务需要关注历史中的不同位置。

注意：这是论文提出的动机和解释，是否真的成立，要看实验，不是因为模型用了 Attention 就自动成立。

### 5.3 输入表示

论文中的直观形式是：

```text
输入表示 = 物品 Embedding + 位置 Embedding
```

物品 Embedding 告诉模型“是什么”，位置 Embedding 告诉模型“在序列的哪个位置”。序列过长时保留最近的 `maxlen` 项；不足时左侧补零。

### 5.4 因果 Mask

预测第 `t+1` 个物品时，只允许模型看第 `t` 步及以前的行为，不能偷看未来：

```text
允许：j <= t
禁止：j > t
```

Padding Mask 和 Causal Mask 是两件事：前者处理补齐位置，后者防止未来信息泄漏。

### 5.5 训练目标与测试评价不是一回事

训练时，每个有效位置通常有一个真实的正物品和一个随机负物品，使用二元交叉熵式目标；测试时，课堂材料中的协议是“1 个真实目标 + 100 个随机负物品”，再计算真实目标是否进入 Top-10。

这两个负采样环节不能混为一谈。

## 6. SASRec 论文实验怎么读

课堂把实验问题拆成四类：

| 研究问题 | 应寻找的证据 |
|---|---|
| SASRec 是否优于已有序列推荐方法？ | 多数据集主结果表 |
| 哪些组件影响效果？ | 受控消融实验 |
| 训练是否高效，能否处理更长序列？ | 时间、收敛和长度实验 |
| 注意力是否呈现位置或物品模式？ | 注意力可视化 |

课堂对 SASRec 原文协议的重点提取：隐式反馈按时间排序；过滤交互过少的用户和物品；最后一次交互测试、倒数第二次验证、其余训练；使用 Hit@10 和 NDCG@10；评价时使用 1 个真实目标和 100 个随机负物品。

## 7. 如何制作自己的精读笔记

建议使用以下模板：

```markdown
# 论文标题

## 1. 论文身份
- 作者：
- 会议/期刊：
- 年份：
- DOI/正式来源：
- 本次阅读目的：

## 2. 三问答案
### 2.1 解决什么问题？
### 2.2 如何解决？
### 2.3 如何证明？

## 3. 方法数据流
原始数据 -> 表示 -> 模块 -> 打分 -> loss

## 4. 实验协议
- 数据集与过滤：
- 切分：
- 正负样本：
- 候选集：
- 指标：
- baseline：

## 5. 主张—证据表
| 作者主张 | 直接证据 | 我的判断 | 证据边界 |
|---|---|---|---|

## 6. 具体疑问
- 原文位置：
- 我已经理解的部分：
- 我尝试过的解释：
- 下一步怎么查：

## 7. AI 使用记录
- AI 做了什么：
- 使用了哪段原文：
- 我核对了什么：
- 最终修正：
```

## 8. AI 能帮什么，不能替你判断什么

AI 可以帮助拆术语、解释公式、提取实验字段、整理跨论文对比和生成待验证问题；但论文身份、DOI、版本、数字、实验协议、公平性和证据边界必须回到原文、正式来源、代码和日志人工核验。

## 9. 第六课作业对应的完成标准

选择第五课找到的一篇论文，提交一份精读 Markdown 笔记，至少包含：论文身份和版本、三问答案、方法数据流、关键公式或模块、实验设计、主张—证据表、具体疑问、AI 使用与人工核验记录。

## 10. 给零基础学习者的记忆方式

不用背整篇论文，也不用背所有公式。先记住：

```text
论文为什么做？
输入是什么，输出是什么？
中间经过哪些模块？
训练时用什么目标？
实验用什么证据证明？
这个证据到底能证明到哪一步？
```
