# 第五次课：从兴趣到研究方向——论文检索与整理

> 本节课的核心不是马上确定最终研究方向，而是学习如何从一个模糊兴趣，逐步找到论文、判断论文，并形成可继续探索的方向。

## 1. 科研探索流程

```text
产生兴趣
→ 拆分关键词
→ 中英文检索
→ 找到论文候选
→ 判断相关性和质量
→ 获取正式版本与 PDF
→ 整理到 Zotero / Obsidian
→ 阅读并记录问题
→ 逐步收窄研究方向
```

研究方向不是第一次就决定好的，而是在阅读、实践、比较和讨论中逐渐形成的。

## 2. 不要急着确定方向

零基础阶段不需要马上确定一个终身研究方向。当前选择的是“学习入口和探索方向”。

合理过程是：先选一个宽方向，找综述和入门论文，了解它研究什么问题，比较不同方法、数据和任务，再结合自己的基础和课题组方向决定是否深入。

不要因为一个模型很新、标题很热门，就直接把它当成自己的研究方向。

## 3. 如何拆分检索关键词

模糊关键词“推荐系统”可以逐步细化为：

```text
推荐系统
→ 序列推荐
→ Session-based Recommendation
→ Next-item Prediction
→ Transformer Sequential Recommendation
→ Long-term and Short-term Interest Modeling
```

关键词可以分为四层：

| 层次 | 示例 |
|---|---|
| 领域词 | recommender systems, recommendation |
| 任务词 | next-item prediction, top-N recommendation |
| 方法词 | sequential recommendation, graph neural network |
| 问题词 | cold-start, long-tail, popularity bias |

常见中英文对应：

| 中文 | 英文 |
|---|---|
| 序列推荐 | sequential recommendation |
| 会话推荐 | session-based recommendation |
| 下一物品预测 | next-item prediction |
| 图推荐 | graph-based recommendation |
| 多模态推荐 | multimodal recommendation |
| 对比学习推荐 | contrastive learning for recommendation |
| 频域推荐 | frequency-domain recommendation |
| 扩散推荐 | diffusion recommender systems |
| 生成式检索 | generative retrieval |
| 大模型推荐 | large language models for recommendation |

## 4. 一个方向要先回答的问题

1. 这个方向研究什么对象？
2. 它解决什么问题？
3. 输入数据是什么？
4. 最终预测什么？
5. 常见方法有哪些？
6. 使用什么评价指标？
7. 与哪些方向相交？
8. 是否有公开数据和代码？
9. 是否有综述或代表论文？
10. 我目前最不理解什么？

如果这些问题完全答不上来，说明还在探索阶段，不需要急着下结论。

## 5. 论文检索方法

推荐搜索顺序：

```text
中文关键词
→ 英文关键词
→ 加 survey / review
→ 加 task / dataset / benchmark
→ 加 conference / journal
→ 核对 DOI、作者、年份和代码
```

以序列推荐为例：

```text
序列推荐 综述
sequential recommendation survey
next-item prediction benchmark
Transformer sequential recommendation
SASRec sequential recommendation
```

每组检索记录：关键词、平台、搜索时间、找到的论文、相关结果、不相关结果，以及为什么继续或停止这个关键词。

推荐平台：

| 平台 | 主要用途 |
|---|---|
| Google Scholar | 广泛搜索、引用和相关论文 |
| DBLP | 计算机论文作者、会议和期刊元数据 |
| ACM Digital Library | ACM 会议和期刊 |
| IEEE Xplore | IEEE 会议和期刊 |
| arXiv | 较新的预印本 |
| GitHub | 查找代码和实验实现 |

## 6. 如何判断论文值不值得读

先检查标题、作者、年份、会议或期刊、DOI、正式版本、代码和数据。

再检查：研究问题是否相关、任务是否清楚、数据和切分是否完整、方法是否能理解、baseline 是否合理、指标和实验条件是否清楚、是否能复现。

优先阅读综述、经典基础论文、任务清楚且代码公开的论文，以及与课题组方向直接相关的论文。

暂时降低优先级：只有标题很新但完全看不懂的论文、没有数据/指标/baseline 细节的论文、复杂度远超当前基础的论文，以及无法核对来源的文章。

## 7. DBLP、Google Scholar、DOI 的分工

- DBLP：确认作者、标题、会议/期刊和年份；
- Google Scholar：查找相关论文、引用和不同版本；
- DOI/正式出版页面：确认正式出版信息、卷期和页码。

引用数量只能作为参考，不能直接等同于论文质量。同一工作可能同时出现在 arXiv、会议、期刊扩展版、作者主页和 GitHub，整理时要区分版本，避免重复统计。

## 8. Zotero、Obsidian 和 GitHub 的分工

```text
Zotero：论文、PDF、作者、期刊、标签和引用
Obsidian：概念、论文理解、知识关系和研究问题
GitHub：课程笔记、代码、实验记录和可公开成果
```

论文状态可以设置为：

```text
待筛选 → 已保存 → 待读 → 阅读中 → 已读 → 可复现
```

每篇论文至少记录：为什么保存、研究问题、方法关键词、数据集、指标、是否有代码、当前是否看懂、下一步要查什么。

## 9. 论文代码与复现判断

看到代码仓库不能只看“能不能运行”，还要检查 README、Python 和依赖版本、数据和预处理、训练/测试命令、随机种子、配置、日志、指标，以及 demo 和正式实验的区别。

如果代码能运行，但不能解释数据切分、指标和 baseline，还不算真正理解复现。

## 10. 从论文中提炼研究问题

重点追问：

- 旧方法哪里不够？
- 数据有什么困难？
- 方法针对稀疏、冷启动、长尾、兴趣变化还是多模态噪声？
- 模型假设了什么？
- 正样本和负样本如何定义？
- 有没有使用未来信息？
- baseline 是否足够强？
- 数据划分、负采样和指标是否合理？
- 是否做了消融和多次运行？

可延伸问题包括换数据集、换时间切分、检查长尾用户、检查冷启动物品、比较不同负采样，以及加入效率、多样性或公平指标。

## 11. 课后作业：推荐方向卡片

宽方向可以选择：序列推荐、图推荐、多模态推荐、多行为推荐、大模型推荐、生成式检索、因果与可信推荐。

细分例子：

```text
序列推荐 → 下一物品预测
图推荐 → 用户—物品图表示学习
多模态推荐 → 文本和图像特征融合
多行为推荐 → 点击、收藏和购买联合建模
大模型推荐 → LLM 作为语义增强器
生成式检索 → Semantic ID
```

方向卡片至少包含：选择方向、选择原因、中文关键词、英文关键词、研究问题、输入数据、预测任务、至少两类方法、至少两个指标、英文论文、搜索过程和当前不理解的问题。

最低要求：至少 5 个中英文术语、2 类方法、1 种任务或数据形式、2 个评价指标、2 组真实中英文检索尝试，以及 1 个当前没有理解的问题。

本次选择的是学习方向，不是最终科研方向定稿。找不到论文也可以，但要记录搜索过程和困难。

## 12. 新手阅读论文的顺序

```text
标题和摘要
→ 引言中的研究问题
→ 图 1 或方法总览
→ 任务和数据
→ 实验表格
→ 方法细节
→ 公式和代码
```

第一遍只回答：这篇论文解决什么？为什么需要这个方法？它在什么条件下有效？不懂的公式先标记，不要卡在一个公式上停留很久。

## 13. 本节课最重要的结论

1. 研究方向是通过检索、阅读、实践和比较逐步形成的。
2. 关键词要从宽到窄，并同时使用中文和英文。
3. 论文检索要记录过程，不能只保存最后结果。
4. DBLP、Google Scholar、DOI、Zotero、Obsidian 和 GitHub 分工不同。
5. 论文能否复现，不只看代码能否运行，还要看数据、版本、切分、指标和实验条件。
6. 新手先做方向卡片，再逐步形成论文阅读和研究问题。
7. 先学会判断论文和实验，再追逐复杂模型。

## 15. PPT 补充：第五课的具体操作标准

### 15.1 论文版本和评价信息

- 会议论文：核对会议名称、年份和正式论文集。
- 期刊论文：核对期刊、卷期、页码、年份和 DOI。
- 预印本：记录版本号、提交日期，并继续检查后续是否正式发表。
- arXiv 是预印本平台，不等于已经被会议或期刊录用。
- CCF A/B/C、JCR 分区和中科院分区是不同体系；载体等级只能辅助排序，不能替代对单篇论文的问题、方法、证据和复现条件的判断。

### 15.2 从方向卡片生成检索式

把检索式拆成：

```text
研究对象 × 任务 × 方法或机制 × 具体问题 × 文献角色
```

以序列推荐为例，可以按以下顺序迭代：

```text
sequential recommendation
-> "sequential recommendation" survey
-> "sequential recommendation" self-attention
-> "SASRec" sequential recommendation
-> SASRec cited by / related work
```

每一轮都记录：为什么增加、删除或替换关键词；结果过宽、过窄还是偏题；下一轮准备怎样改。

### 15.3 Scholar、DBLP 和正式来源的分工

```text
Google Scholar：广泛发现、引用关系、相关文章和多个版本
DBLP：核对计算机论文的作者、载体、年份和 BibTeX
DOI / 出版社 / 会议官网：确认正式发表版本
```

引用量不能单独证明质量，能下载 PDF 也不等于已经确认正式发表。

### 15.4 10 分钟快速筛选

| 时间 | 查看内容 | 要回答的问题 |
|---|---|---|
| 1 分钟 | 元数据 | 论文身份和版本是否明确？ |
| 2 分钟 | 摘要 | 任务、方法和主要结论是什么？ |
| 3 分钟 | 引言与结论 | 为什么做，与已有方法有什么区别？ |
| 2 分钟 | 模型图和主结果表 | 作者用什么证据支持主张？ |
| 2 分钟 | 代码、数据和项目页 | 是否值得继续阅读或复现？ |

### 15.5 工具不要混用职责

- Zotero：论文元数据、PDF、标签和引用。
- Obsidian / Markdown：概念、论文理解、研究问题和知识关系。
- GitHub：课程笔记、代码、实验记录和可公开成果。
- VS Code：编辑、运行、调试和连接环境。
- Jupyter：交互式数据检查和小规模实验。
- TensorBoard：本地损失、指标和训练过程观察。
- Overleaf / LaTeX：论文结构、公式、图表和参考文献。

同步成功不等于独立备份；未公开论文、审稿材料、实验室数据、密码、私钥和 Token 不应随意上传。

### 15.6 第五课作业标准

- 基础版：2 组真实检索记录、至少 1 篇完整文献卡片、Zotero 分类或条目记录。
- 标准版：3 组检索迭代、3 类候选论文卡片、Zotero 归档与工具组合。
- 进阶版：5 篇候选论文、双向引用追踪与关系链、导出并核验 BibTeX。

共同终点是选择 1 篇第六课精读对象，说明选择理由，并写出最想读懂的 3 个问题。

本笔记根据课程视频音频转写和课程上下文整理。自动中文语音识别对英文术语、专有名词和人名可能存在误识别，因此具体论文名称、会议等级和现场示例应以视频画面、老师提供的材料和正式论文页面为准。本笔记保留课程方法和流程，没有把不确定的转写片段当作确定事实。
