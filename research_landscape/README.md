# 推荐系统研究入门包（2026）

本目录面向重庆大学大数据与软件学院文俊浩、周魏课题组的零基础新生，内容更新至 2026 年 7 月 15 日。

## 交付内容

- [推荐系统最新综述](./recsys_survey_2026.md)：从经典协同过滤到可信、生成式与智能体推荐的研究全景。
- [推荐系统学术地图](./recsys_academic_map.md)：研究分支、技术依赖、课题组对齐方向与选题入口。
- [零基础学习路径](./recsys_beginner_learning_path.md)：24 周学习计划、阶段产出和通过标准。
- [核心论文阅读清单](./recsys_core_reading_list.md)：按“先读—复现—进阶”组织的论文队列。

## 建议使用顺序

1. 先读学术地图，知道整个领域有哪些分支。
2. 阅读综述的第 1、3、8、9 节，建立总体判断。
3. 按学习路径完成 Python、PyTorch 和推荐系统基础。
4. 从论文清单的 A 组开始阅读与复现。
5. 与导师确认具体方向后，再进入 B/C 组专题论文。

## 当前最适合的课题组对齐路线

```text
LightGCN / SASRec 基线
  → 多行为与多兴趣建模

  → 因果去偏与可信推荐

```
