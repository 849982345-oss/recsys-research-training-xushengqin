## 三、工具学习

### 1. VS Code

VS Code 可以用于编写 Python、编辑 Markdown、管理项目目录、使用集成终端、查看 Git 修改，以及配合 Codex 阅读和修改项目。

今天学习的基本操作包括：

- 打开整个课程仓库；
- 创建文件和文件夹；
- 编辑 `.md` 文件；
- 在集成终端中执行命令；
- 使用 `Ctrl + Shift + V` 预览 Markdown。

### 2. Obsidian

Obsidian 可以直接打开 Markdown 笔记目录，适合通过链接、标签和知识图谱整理知识之间的关系。

目前课程正式笔记仍保存在 GitHub 仓库中，Obsidian 主要用于辅助阅读和组织，避免在多个位置维护不同版本。

### 3. Git 与 GitHub

Git 用于记录本地文件变化和版本历史，GitHub 用于在线保存、展示和协作管理仓库。

基本工作流程是：

> 修改文件 → 查看差异 → 暂存修改 → 创建提交 → 推送到 GitHub

常用命令：

```powershell
git status
git diff
git add 文件名
git diff --staged
git commit -m "提交说明"
git push
```

创建并连接仓库时还会使用：

```powershell
git init
git branch -M main
git remote add origin GitHub仓库地址
git remote -v
git push -u origin main
```

### 4. Codex

Codex 可以辅助阅读仓库、创建和修改文件、整理 Markdown、解释代码、运行命令，以及检查 Git 状态和差异。

计划采用的流程是：

> 明确任务 → Codex 修改文件 → 查看 `git diff` → 人工检查 → 提交并推送 → 检查 GitHub

使用 Codex 时需要关注它修改了哪些文件、是否删除了有效内容、执行了哪些命令，以及操作结果是否真实完成。
