## 三、今天学到的知识

### 1. Conda 环境

Conda 环境用于隔离不同项目的 Python 和依赖。终端前面的 `(lesson03)` 表示当前已经进入该环境；`where.exe python` 可以确认实际使用的 Python 路径。

### 2. VS Code 与 Python 解释器

VS Code 只是编辑器和终端工具，真正运行代码的是当前选择的 Python 解释器。必须同时检查 VS Code 的 Python Interpreter、终端中的 Conda 环境、Python 版本和 Python 路径。

### 3. PowerShell profile

PowerShell 启动时会加载 profile.ps1。执行策略禁止脚本时，Conda 初始化可能失败。使用 CurrentUser 范围的 RemoteSigned 可以允许本地配置脚本运行，不应随意使用 Unrestricted。

### 4. PyTorch 与 CUDA 兼容性

`torch.cuda.is_available()` 为 True 并不代表所有 GPU 运算都兼容。RTX 5070 Ti 的计算能力为 `(12, 0)`，PyTorch 2.12.1+cu126 出现架构不兼容警告，换成 cu130 后正常。

### 5. SASRec

SASRec 是序列推荐模型，根据用户历史交互顺序预测下一个物品。主要流程是：物品 Embedding、位置 Embedding、因果 Self-Attention、序列表示和候选物品打分。

### 6. 数据切分与指标

Smoke 数据按照时间顺序划分训练、验证和测试，避免未来行为泄漏。HR@10 关注目标是否进入前十名，NDCG@10 还关注目标在前十名中的具体位置。

### 7. Smoke Test

Smoke Test 主要验证环境、数据、模型、训练、评测和输出是否完整可运行，不是正式的模型效果实验。合成小数据上的高指标不能直接代表真实推荐系统效果。

## 四、实验结果

实验环境：

- Python 3.10.20；
- PyTorch 2.12.1+cu130；
- CUDA runtime 13.0；
- NVIDIA GeForce RTX 5070 Ti；
- 显存约 16 GB。

GPU 训练配置：10 个 epoch、batch size 32、最大序列长度 20、hidden size 64、2 个 attention heads、2 个 Transformer blocks。

最终结果：

- Loss：1.3830 → 0.9981；
- Valid HR@10：0.2578 → 0.8047；
- Valid NDCG@10：0.1180 → 0.6363；
- Test HR@10：0.8672；
- Test NDCG@10：0.6620；
- Torch allocated memory：69.8 MiB；
- Torch reserved memory：92.0 MiB。

## 五、遇到的问题与解决方法

### 问题 1：PowerShell 禁止加载 profile.ps1

解决方法：在 CurrentUser 范围设置 RemoteSigned，让 Conda 初始化脚本能够加载。

### 问题 2：cu126 能识别 GPU 但出现 sm_120 不兼容警告

解决方法：卸载 cu126，改装 PyTorch 2.12.1+cu130，并重新验证 CUDA。

### 问题 3：PyTorch 提示缺少 NumPy

解决方法：在 lesson03 环境中安装 NumPy。

## 六、反思

这次虽然主要是按照命令操作，但已经理解了环境、代码、数据和实验结果之间的关系。以后遇到问题时，应该先判断是环境层、数据层、模型层还是评测层的问题，而不是直接重装所有软件或修改模型代码。

命令不需要全部背下来，但要记住常用命令的用途，并能看懂环境版本、设备、指标和日志。
