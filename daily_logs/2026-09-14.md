## 做了什么

按 24 周路径把 NCF（WWW 2017）完整复现了一遍，作为阶段 3 的收口。

- **数据**：用论文官方仓库 `hexiangnan/neural_collaborative_filtering` 的 `Data/` 已处理产物（`ml-1m.train.rating` 994,169 行 / `test.rating` 6,040 行 / `test.negative`），避免自己重做预处理引入协议偏差。
- **代码**：社区 PyTorch 移植 `guoyang9/NCF`，逐模块核对模型、损失、采样、评估；补 `--model` 运行参数，改掉 tensorboardX 依赖、Windows 下 `num_workers` 置 0，加逐 epoch 指标落盘 `logs/*.tsv`。
- **训练**：factor 8 / batch 256 / lr 1e-3 / Adam / 1:4 负采样 / 50 epoch，单卡 RTX 5070 Ti，每个 epoch 26–38 秒。

## 踩过的坑（可复用）

1. `Data/` 是大写目录，小写 404；
2. 代理会把小文件静默截断（`data_utils.py` 被截到 1443 字节），必须按 GitHub API 的 size 校验字节数；
3. `pip install torch` 会被版本判定挡住不换包，必须 `--force-reinstall --no-deps` + cu130 index；
4. 课程目录里的 `sasrec_pytorch/data/ml-1m.txt` 是**模拟数据**（user 1 的 item 连续递增 1..35），不能当真实 ML-1M 用。
